#  Simple Python Chatbot

This is a basic rule-based chatbot built using Python.  
It responds to simple user inputs like greetings, questions, and goodbye messages.


##  Features

- Responds to greetings like "hello" and "hi"
- Answers basic questions like "how are you"
- Introduces itself when asked its name
- Exits conversation when user types "bye"
- Simple and beginner-friendly logic


## Technologies Used

- Python
